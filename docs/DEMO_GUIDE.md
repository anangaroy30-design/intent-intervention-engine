# Demo guide

1. Launch the app in demo mode; no server is required.
2. Create a session with a short duration.
3. Start the session and tap **Advance demo time**.
4. When the planned duration is reached, respond to the intervention.
5. Inspect History and Insights; the local record updates.
6. Open Settings to see monitoring consent and usage access status.
7. Optionally start the API and test its health endpoint at `/api/health`.

Always explain that demo-time advancement is simulated and not actual phone usage.
