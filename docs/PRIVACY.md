# Privacy notes

INTENT is designed to request usage access only after explaining the feature. UsageStatsManager can report app usage summaries, but it cannot reveal the private contents of other apps. Users can disable monitoring and use manual session timers instead.

The demo clock and sample records are simulated. The drift score is an illustrative heuristic, not a clinical assessment. Do not send usage histories to external AI services without explicit consent. This starter is not a substitute for a privacy/security audit or legal review.
